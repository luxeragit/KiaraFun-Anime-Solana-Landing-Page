# KIARAFUN — PREMIUM ANIME SOLANA LAUNCHPAD
## Phase 1: Brand Website & Cinematic Landing Page

You are a senior creative director, frontend engineer, interaction designer, and brand identity specialist.

Build a production-quality, fully responsive landing page for **KiaraFun**, an anime-inspired token launchpad being developed on Solana Mainnet.

The website must feel like a genuinely original, carefully art-directed digital product.

It must NOT look like a generic AI-generated SaaS website, a common Web3 landing page, or a recycled Tailwind template.

Our visual identity is based on the anime character image provided with this project.

**Brand:** KiaraFun  
**Blockchain:** Solana  
**Category:** Token Launchpad  
**Tagline:** Every Coin Has a Story.  
**Personality:** Cheerful, expressive, imaginative, playful, welcoming, trustworthy, and premium.

This phase is strictly focused on the landing page. Do not build token deployment contracts, trading engines, bonding curves, or fake launchpad functionality yet.

---

# 1. PRODUCT VISION

KiaraFun is an upcoming Solana token launchpad that combines token creation, community storytelling, and transparent launch information.

We want to offer a more expressive alternative to conventional meme-token launchpads.

Our future product differentiation revolves around three concepts:

### Kiara Chapters

Each token has an evolving story.

Future token pages can combine creator descriptions, development updates, community moments, and verifiable on-chain milestones in a chronological narrative.

### Launch Transparency

Future launch pages will make important token and launch information easier to inspect.

This may include mint authority, freeze authority, token supply, creator allocation, holder concentration, applicable fees, launch configuration, and liquidity or graduation progress.

Every displayed verification claim must ultimately be supported by actual on-chain data.

### Kiara Spotlight

A discovery experience designed to make interesting projects easier to find through their creative identity, authentic community activity, and development progress.

Spotlight ranking mechanics have not been finalized. Do not imply that the service is already operational.

These are planned product directions. The landing page must communicate them as the vision for KiaraFun, not as existing production functionality.

The website should make people excited about KiaraFun without promising guaranteed financial returns, completely bot-free launches, or risk-free trading.

# 7. THE MAIN EXPERIENCE — CONTINUOUS SCROLL STORYTELLING

This requirement is extremely important.

I do not want a conventional website where users scroll through unrelated rectangular sections.

I want a continuous, connected scroll experience.

The page should unfold like an interactive story.

Use GSAP ScrollTrigger and Lenis to connect sections into one visual narrative.

Implement a specially designed scroll storytelling sequence.

On desktop, use a carefully controlled pinned section where multiple text statements appear progressively while the environment changes.

The sequence:

### SCENE 01 — THE SPARK

Small label:
"CHAPTER 01 / THE IDEA"

Large text:
"Every great launch starts with a little imagination."

The text should reveal progressively as the user scrolls.

A thin decorative line extends alongside the typography.

### SCENE 02 — THE PROOF

Small label:
"CHAPTER 02 / THE DETAILS"

Large text:
"A good story deserves a clearer launch."

The previous text elegantly moves or fades away.

The next statement appears in its place.

The visual background transitions toward a lighter cloud-white environment.

### SCENE 03 — THE COMMUNITY

Small label:
"CHAPTER 03 / THE PEOPLE"

Large text:
"The next chapter belongs to everyone."

Introduce small, original decorative graphic elements that visually suggest a growing community.

Do not use generic 3D coins or stock crypto illustrations.

### Animation behavior

- Each statement must respond to scroll progress.
- Text reveals should be smooth and readable.
- Use restrained masking, clipping, or line-by-line transitions.
- Avoid excessive character-by-character animations.
- Keep movement fluid with carefully managed easing.
- The user must be able to scroll both forward and backward naturally.
- Do not hijack scrolling.
- Do not add artificial delays between sections.
- Avoid layout jumps when pinning begins or ends.

On mobile, simplify pinned animations into natural scroll-triggered reveals.

Keep all essential text accessible and visible even if JavaScript animation fails.

Support reduced-motion preferences.

### Hover

- Soft typography motion
- Subtle button displacement
- Small directional icon transitions
- Smooth navigation states
- Gentle interactive highlights

### Page transitions

- Cohesive transitions between backgrounds
- No abrupt layout changes
- No excessive fade-in animation on every paragraph

### Performance

Use GPU-friendly transform and opacity animations where possible.

Avoid unnecessary blur animation on large layers.

Ensure GSAP triggers refresh correctly after image loads and responsive layout changes.

Properly clean up animation contexts in React components.

Synchronize Lenis and ScrollTrigger without creating multiple animation loops.

Animations must pause or simplify appropriately for users who prefer reduced motion.

Avoid enormous animation libraries beyond what is necessary.
